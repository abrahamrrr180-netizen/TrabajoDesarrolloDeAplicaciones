Sobre mí

Me llamo Abraham Rajo Rodríguez y estudio el Grado en Ingeniería Informática en la Universidad Internacional de La Rioja (UNIR).

Hice este blog como práctica de la asignatura Desarrollo de Aplicaciones en Red. Escribo sobre proyectos que programo, cálculos que me ayudan a decidir y recetas que he ido ajustando.

Cómo está hecho

  • HTML y CSS escritos a mano, sin frameworks.
  • Eleventy para generar las páginas a partir de las entradas en Markdown.
  • GitHub Pages para publicarlo.
  • Las imágenes las generé yo con un pequeño script de Python.
